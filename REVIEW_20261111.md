# BoltTool source review and stabilization — 2026-11-11

## Scope / environment

- Reviewed the user's uploaded `BoltTool_20261111.rar` and handoff. This ZIP is an editable **source package**, not a compiled/installed AutoCAD plugin.
- Target: AutoCAD 2027 on Windows x64; C# .NET 10 WPF; `BOLTTOOL`, `BOLTEDIT`, `BOLTTORQUE` commands.
- The archive's `bin` DLL was from the old known-working commit and is **NOT** a build of the new v2 element-stack code.
- This review machine does **not** have the Windows .NET 10 SDK or AutoCAD 2027 managed assemblies, so neither the plugin nor the regression-test executable could be compiled or run here.

## Source modifications relative to the uploaded RAR

1. **Separated clamp thickness from adjustable gaps** (`Data/BoltJob.cs`, `Geometry/PartBuilder.cs`, `Geometry/StackMover.cs`, diagram): `ClampLength` always means solid plates. Every `StackItem.Gap`, including the first nut-side element, now means **empty space immediately before that element**. Dragging the last head-side washer outward shifts the plate and nut-side stack without reducing plate thickness; a nut-side part stops at the plate surface. Same-side reorder/ghost stays available; crossing the plate separator is intentionally blocked.
2. **Bolt length synchronization** (`UI/BoltToolWindow.xaml.cs` and XAML): in automatic mode the Part-tab length shows the computed required standard bolt length; selecting a specific entry or entering a different number changes to manual. Assembly tab has the checkbox to restore automatic. Added an explicit explanation next to the length selector.
3. **Sticky preview** (`UI/PreviewControl.cs` and UI): editing bolt/washer values preserves the orbit framing, zoom and pan. New `Fit view` button and preview double-click explicitly reset fit.
4. **Grip discovery**: the blue preview triangles have visible `L` and `Clamp` labels and hover descriptions. The former changes bolt length; the latter changes joined-part thickness. These are custom grips, **not native AutoCAD dynamic-block parameters**.
5. **Numeric validation**: reject NaN/Infinity from text fields and sanitized persisted element gaps, thicknesses, diameters, clamped thickness and length before layout.
6. **Torque explanation** (`TorqueCalculator.cs`, UI): 70% utilisation is explicitly an example selected by the user, not a requirement of JIS B 1083. The JIS option is labelled a simplified K-method estimate rather than a certified JIS joint calculation. For electrical terminal / conductor materials, label the result as a **mechanical estimate, NOT a specified terminal tightening torque**, and direct users to equipment manufacturer specifications.
7. **Block-cache correctness** (`Cad/BlockFactory.cs`): geometry cache/hash version v5 includes full-precision part dimensions and the complete user-editable standard size row. Prevents reuse of an old block with different configured washer dimensions or custom table values.
8. **Windows install messaging**: install script warns of another installed bundle containing the same DLL. It does not delete existing folders automatically; user must verify and remove any outdated bundle to resolve an old window title.
9. **Documentation / regression tests**: added a small standalone `tests/BoltTool.CoreTests.csproj` linking only the model/geometry/torque code. It includes checks for M8 with 58-mm clamp, automatic lengths, head/nut gap movement, touching/no overlap, same-side swap, equal double nuts, invalid values, and torque-coefficient identity.
10. **Measure-label accuracy**: Shift measurements in the preview are labeled `mm (2D)`; they are distances in the current *orthographic projection*. They are not a substitute for 3D true distances between model points.

## Features present in uploaded v2 source but not yet proven in AutoCAD

- Washers, spring washers and nuts in any order within head / nut side, editable thickness and outside diameter, preset double nuts (two equal-height nuts), flange nut approximation.
- Editable gap fields, multi-selection distance labels, green ghost on drag/swap; head and nut-side order summary diagrams.
- Direct protrusion in mm or thread pitches; per-size default length; 2D / mesh / faceted solid block outputs.
- Shift+click 2D-measuring arrows; Save JPG snapshot; user-defined block origin at head top, bearing face, other end contact, or thread end.
- Stretch grips on inserted drawing blocks, which use plugin-specific overrules and require BoltTool to be loaded; they do not create native AutoCAD dynamic-block actions.

## Known limitations / open work

- **No verified compilation of v2.** Windows compilation errors and actual AutoCAD API/runtime behavior may still need correction. Do not place production-critical drawings before testing.
- **No native dynamic-block parameters/actions created.** Existing alternative is plugin-provided length/clamp grips, or preauthored dynamic-block templates if required.
- Drag-swap crossing the **clamped plate separator** is blocked to prevent impossible collisions. To move a washer from head side to nut side, use the element list.
- Elements share the bolt's thread nominal size; currently only per-item thickness and outside diameter are editable.
- The JIS/ISO dimensional tables were initially typed/approximated and are **not independently certified against official standards**. In particular check JIS head/nut sizes, spring washers and flange nut dimensions with catalog/drawing before use.
- Tightening-torque inputs (friction, allowable bearing pressure, preload utilisation, etc.) are assumptions. For F8T/F10T structural-friction joints use the applicable certified bolt set and construction specification; for electrical terminals and busbars follow the **specific manufacturer's rated tightening torque, washers and contact treatment**.
- Shift measuring snaps to rendered polyline vertices; it does not currently snap to all CAD midpoints/centers, nor measure unprojected 3D lengths.
- Washers' convex-hull 2D wipeouts can obscure central holes in end views; existing 3D detailed-thread solids can remain meshes.
- Changes to already-placed legacy blocks may require re-inserting or `BOLTEDIT`.
- Japanese translations remain partially machine-reviewed; a full Japanese UI QA pass is pending.

## Windows build and acceptance test

Close AutoCAD. Copy the source folder to a local path (e.g. `C:\Dev\BoltTool`). Use a machine with .NET 10 SDK and AutoCAD 2027 installed.

```bat
cd C:\Dev\BoltTool
dotnet --version
dotnet run --project tests\BoltTool.CoreTests.csproj -c Release
build.bat
install.bat
```

If SDK/build output reports errors, copy the complete error text. If `build.bat` succeeds and `install.bat` completes, start AutoCAD 2027, enter `BOLTTOOL`, and verify:

1. M8, assembly checked, clamp 58 mm: length automatically exceeds 25 mm and follows the computed standard length. Choosing a specific length makes it manual; ticking the automatic checkbox restores automatic.
2. Drag head-side washer 12 mm outward, check dimension, clamp unchanged and nut-side stack moves; check no overlap with plates. Drag first nut-side washer toward plates, check it stops. Pull a spring past adjacent washer to preview and commit a green same-side reorder.
3. Switch between ISO/JIS, partial/full thread, nut types; create two same-size hex nuts and override either thickness. Check head/nut-side settings and diagrams.
4. Orbit, pan, zoom. Change element thickness and bolt length: camera must not jump; press **Fit view** to recenter. Shift-click two corners to measure, and save JPG.
5. Insert whole assembly and separate linked parts, verify layer 0 ByBlock, wipeout layer and selected base point. Drag both drawing grips (length and clamp); test `BOLTEDIT` on a newly placed block.
6. Verify EN/JP switch; switch materials/methods on torque tab. For conductor materials, confirm the redirection to the manufacturer-specified torque is prominent.
7. Check no second outdated auto-load bundle is installed (if the window title still contains an obsolete brand). Never install the previous archive's `bin` DLL.

**Note:** `build.bat` assumes AutoCAD at `C:\Program Files\Autodesk\AutoCAD 2027`; if installed elsewhere pass `build.bat "D:\path\AutoCAD 2027"`.
